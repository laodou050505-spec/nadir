# 《天底》NADIR Unity 方案

“天底”是天文术语，指观察者正下方的那一点，也引申为最低处。副标题：注意脚下 / Don't look down。

## 顺序

1. 场景做到好看
2. 移植玩法（规则以 `~/hollowfloor/src/logic` 为准，美术不沿用）
3. UI 和边玩边学的教程

## 场景构成

- 大厅 13×13 米，层高 4.6 米；四条走廊各 24 米，层高 3.5 米，尽头是病房门和出口灯。
- 玩区 5×5 块地砖，每块 0.75 米，缝一直铺到大厅和走廊，玩区边界看不出来。
- 地砖下是四十层竖井，近 8 层完整，其余简化。竖井只透过洞可见（Stencil）。
- 大厅只亮两盏对角的灯，光池之间暗下去；走廊隔段亮一盏。

## 光照

| 部分 | 做法 |
| --- | --- |
| 建筑、地板块 | 烘焙光照贴图，非方向性，1024 |
| 道具、人影 | 光照探针 |
| 竖井和井里的东西 | DLD/Shaft 按世界坐标算灯 |
| 地面亮带 | 反射线打到天花平面，查亮灯分布图 CeilMap |
| 灰尘、灯下光雾 | 粒子、叠加网格，靠近时淡出 |

真机不开后处理，HDR 关，MSAA 4x。

## 材质

第二版，处理脚本 `Tools/process_tex3.py`，源图 `ArtSource/TexV2`。

- 贴图 2K，内容是干燥老化：掉漆、裂纹、崩瓷、划痕、积灰。不写“干净、无污渍”，否则生成的是商品样本。
- 每张贴图配法线和遮罩（R 光泽，G 缝隙）。
- 光照贴图用方向性，否则漫反射不响应法线，表面发滑。
- Lit 着色器：第二层采样防重复，世界空间噪声做大尺度老化并打散光泽。
- P2 道具用 `Tools/p2_maps.py` 从贴图推法线和遮罩，再按朝向投影一层划痕。

## 模型

P2 模型一律走：参考图 → 四视图 → 白模 → 审计六视图 → 批准 → 贴图 → 修复（0 开放边、0 非流形）→ 烘焙 2K → LOD0..3。

| 模型 | 用途 |
| --- | --- |
| wheelchair、gurney、medcart、bench、nursedesk、screen、ivstand、cabinet、warddoor | 场景道具（warddoor 只用于走廊尽头） |
| figure | 无脸黑影 |
| hand、climber | 井里爬上来的手和爬行者 |

程序建模：建筑、灯盘、竖井、发光瓶、天花破损。

## 深渊

| 层次 | 做法 |
| --- | --- |
| 井口下几米 | 大厅的光渗下去，再沉入黑暗 |
| 纵深 | 从第二层起井灯才亮，一路缩成光点 |
| 体积 | 八层流动雾（同一网格，只透过洞可见），越深越浓直到全黑 |
| 飞尘 | 粒子缓慢上飘 |
| 巨眼 | 球半径 8 米，比井宽，虹膜填满井底；睁开时停在井口下约 5 米。虹膜有角膜视差，圆瞳孔，被发现时放大。红光很弱，只围着眼睛 |
| 井壁 | 几乎平整，圈梁只凸 8 厘米，长透视线才看得出深 |
| 触手 | 不是手。程序生成，深色厚皮质感，粗细按离梢部的距离算，只从破洞出入，沿原路退回。不做吸盘 |
| 井里的触手 | 贴井壁缓慢摇摆，够不到洞口，随层数增加（最多 7 条） |

试过从洞口往下的光柱，硬边薄板很廉价，已删除，不要再加回来。

## 出口

不用门模型。出口是竖直的空间裂隙：上下尖、边缘被噪声撕开、极细的高温亮线。
透过它按真实视线方向采样金色梦核长廊全景（portal_pano），走动时景物会变，双眼有差异。
碎片集齐后从一条细线慢慢张开，是全场唯一的大面积暖光。

## 黑影

从走廊深处的雾里走出来，进大厅后慢下来并散开。第 3 层起踏进地板，一层比一层往中间挤（离中心最近 1.1 米），永远离玩家 1.25 米以外。
伸手一推，它被推到大厅远端，停一会儿才重新逼上来。

## 关键时刻

- 被抓：触手缠小腿，视线慢慢下沉，拍开才脱身，否则脚下的砖塌掉。
- 坠落：真的掉进井里，看着洞口在头顶远去，约 1.35 秒后淡出。
- 开门：碎片集齐后只有一道细缝。玩家走到跟前，双手捏住往两边拉，拉开 0.4 米算全开；约 10 秒检测不到手时自动打开。
- 传送：裂隙从前方往四周撕开，把视野吞进金色长廊，再被光淹没，约 2.9 秒。

## 界面

平时没有常驻界面。操作只有一种：看着它，捏合。检测不到手时，看够两秒也算按下。

- 安全须知：开局显示，5 秒后才能继续。
- 主菜单：老旧电梯面板，八层楼对应八个按钮，三档模式（普通 / 恐怖 / 全包围），中英文切换。
- 教学：边玩边学，搪瓷提示牌飘在视野下方，图形加一句话，每种只教一次。
- 文字都烘成图片，脚本 `Tools/make_ui.py`，字体 Noto Sans SC / Noto Serif SC（OFL）。

三个版本：普通（透视）、恐怖（透视压暗）、全包围（医院场景）。透视时隐藏建筑，只留地砖和井。

打包：菜单 DLD/4 切到 Android，DLD/5 打包。签名在 `Keystore/`（已写入 .gitignore），不要提交。

## 巡检

菜单 DLD/3 巡检（`Editor/SceneAudit.cs`）。检查看得见的共面重叠（闪烁）和道具真实顶点的穿模。
`MeshKit.Box` 放方盒时自动挑外扩量，让重合的面错开。

## 声音

一次性音效由 `Tools/make_sfx.py` 离线合成，环境声和几段素材来自 ange-embed，见 `Docs/音效来源.md`。
配乐 `Tools/make_music.py`：低频拍频、不协和弦乐、远处合唱、尖细泛音、低频脉动，按危险程度叠加；走调八音盒偶尔从远处走廊传来。
环境循环：底噪、灯管嗡鸣（跟全场亮度走）、井底的风（破洞越多越响）、传送门低鸣、触手摩擦声、心跳（按危险程度加快）。

## 全球化

墙上的导向牌只用图形，不写字。碎片是发光的玻璃安瓿瓶，全场唯一的暖色，用来和冷绿的医院区分。

## 限制

不做血迹、黏液、霉斑、肉质感；不做贴脸、尖叫、闪屏。

## 界面与封面（10-31 真机反馈后重做）

- 电影片头式排版：无底板，文字直接浮在场景里，靠 `DLD/UI` 的模糊聚焦显影入场；字号按统一比例换算（`UILang.MetersPerPixel`），不存在单独拉伸。
- 选择：看着最近的选项 + 捏合；检测不到手时注视 2 秒。
- 难度：简单 / 普通 / 困难，对应透视、透视压暗、医院全场景，规则相同。
- 活动范围：2.5 / 3 / 3.75 / 5 米，超出系统安全区的档位不可选；地图中心对到安全区中心。
- 封面：`Tools/make_cover.py`，产物在 `Docs/封面/`；头显启动画面和应用图标在 `Assets/_DLD/Art/Cover/`。应用名默认 NADIR，中文系统显示“天底”。
