# 素材来源

## 音频

全部由本项目的脚本离线合成，不含任何第三方音频。

| 目录 | 生成脚本 | 内容 |
| --- | --- | --- |
| `Assets/_DLD/Audio/Sfx` | `Tools/make_sfx.py` | 开裂、坠落、灯、门、黑影、巨眼、触手、界面等一次性音效和循环 |
| `Assets/_DLD/Audio/Sfx/end_dawn.wav` | `Tools/make_amb.py` | 结局的鸟鸣和微风 |
| `Assets/_DLD/Audio/Amb` | `Tools/make_amb.py` | 底层氛围（普通 / 困难各两层）、风、木头吱呀、碎石、脚步、低语般的气声 |
| `Assets/_DLD/Audio/Music` | `Tools/make_music.py` | 分层配乐：低频持续音、不协和弦乐群、远处合唱、尖细泛音、低频脉动，以及走调的八音盒和上涌 |

## 字体

界面文字和封面是用这些字体渲染成贴图的（`Tools/make_ui.py`、`make_cover.py`），授权文本都在 `ArtSource/Fonts/`：

| 字体 | 授权 |
| --- | --- |
| Noto Sans SC、Noto Serif SC | SIL OFL 1.1 |
| Long Cang | SIL OFL 1.1 |
| Covered By Your Grace | SIL OFL 1.1 |

## 贴图、模型、封面

- 贴图原图、参考图、封面底图：Tripo 生成（nano banana / seedream），再由 `Tools/process_tex3.py`、`make_cover.py` 处理。
- 道具和黑影模型：Tripo P2 生成，由 `Tools/p2_pipeline.py`、`p2_finalize.py`、`p2_lods.py` 修复、减面和审计。
- 医院建筑、竖井、地砖、护士台、输液架立杆：程序建模（`Assets/_DLD/Editor/KitBuilder.cs`、`SceneBuilder.cs`）。
